TwoArc Autopilot

Short-video publishing assistant for TwoArc's own mobile apps

TwoArc Autopilot is an internal desktop tool used by TwoArc, an independent mobile app studio, to promote its own apps (for example Ranking Filter: Fun Challenge) on TikTok. It is not offered to the public and is only used with TwoArc's own TikTok accounts.

What it does

  • Creates short vertical videos from TwoArc's own app content (ranking packs, app screenshots).
  • Uploads each video to the connected TikTok account as a draft. A team member reviews the draft in the TikTok app, edits it and decides whether to post it.
  • Reads basic statistics (views, likes, comments, shares) of the account's own videos to learn which video styles work best.

TikTok permissions used

  • user.info.basic: shows which account is connected.
  • video.upload: sends a video to the account's TikTok inbox as a draft.
  • video.list: reads the account's own public video statistics.
